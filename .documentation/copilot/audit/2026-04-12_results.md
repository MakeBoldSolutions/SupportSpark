## Top Recommendations

1. Run `/devspark.upgrade` to move the framework from 1.5.0 to 1.5.1 and keep command behavior aligned.
2. Remove or archive the empty root `specs/` directory so `.documentation/specs/` is the only active feature-planning location.
3. Update `README.md` and `.documentation/Guide.md` to describe the current `.documentation/copilot/` layout, including audit output.
4. Isolate preview credentials behind an explicit demo-only helper or configuration boundary so client auth code does not embed plaintext passwords inline.
5. Split `server/routes.ts`, `server/storage.ts`, and `client/src/components/ui/sidebar.tsx` only when the next related change touches them; they are maintainability risks, not emergency defects.
